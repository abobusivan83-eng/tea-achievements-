# Ресурсы для Android/iOS сборки

Сейчас в каталоге лежат **временные** PNG под тестовый APK (`icon.png`, `adaptive-icon.png`, `splash.png`). Перед продакшеном замените на финальный бренд.

## Обязательно заменить позже

| Файл | Назначение | Рекомендации |
|------|----------------|---------------|
| `icon.png` | Иконка приложения | PNG **1024×1024**, без прозрачных полей по краю (launcher ожидает заполнение). |
| `adaptive-icon.png` | Foreground adaptive icon Android | PNG **1024×1024**, важное содержимое в **центральном круге ~66%** (обрежет система). |
| `splash.png` | Splash | Рекомендуется вертикаль **1284×2778** (или кратный 3×) или квадрат 2048 под `resizeMode: contain`. |

Ссылки в манифесте: `mobile-app/app.json` → поля `expo.icon`, `expo.splash.image`, `expo.android.adaptiveIcon.foregroundImage`.
